# Relationship with the Original Caveman Project

This project is a **companion**, not a fork or replacement.

## What We Share

Both projects aim to reduce token waste. Both apply compression to AI communication.
Both trace roots to the Grug Brained Developer philosophy.

## How We Differ

| Dimension | Original Caveman (JuliusBrussee) | This Project |
|-----------|----------------------------------|--------------|
| **Primary focus** | Universal token compression for all agent tasks | Academic & office document workflow |
| **Scope** | Code+chat+tool-output compression | Thesis, journals, reports, DOCX/PDF review |
| **Engine model** | Compression engine + skill (v2.1) | AI-prompt-based compression layer only |
| **Philosophical layer** | Minimal | Full Grug reasoning engine included |
| **Target users** | Developers, all coding agents | Students, researchers, office workers |
| **Deployment** | CLI, MCP, npm, agent SDK | Web/app (no CLI) |
| **Language focus** | Universal (all languages) | English + Indonesian |
| **Iteration** | Standard non-looping | Optional Ralph Wggum loop |

## What You Should Use When

- **For everyday coding and general AI agent work:** use the original [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) — it has a full compression engine, MCP middleware, and support for 30+ agents. |
- **For thesis writing, journal articles, office reports, and DOCX/PDF review:** use this project — the Grug reasoning engine handles document strategy, the caveman skill handles token compression, and the Ralph Wiggum loop handles iterative refinement. |
- **For maximum token savings on coding tools:** use both. Load the original caveman skill into your agent, then use this project's Grug engine for document-specific work. |

## The Grug Engine Advantage

This project ships `claude-reasoning-caveman.skill` — a full dual-mode reasoning engine:

- **Internal Grug voice:** planning, fear-assessment, tool selection — all in caveman-speak
- **External professional voice:** formal, academic, polished output

The original caveman doesn't provide this. It compresses tokens. We compress tokens *and* provide a reasoning framework.
