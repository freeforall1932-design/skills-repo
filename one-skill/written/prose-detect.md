The prose-only companion to the design filter: named patterns, quoted
evidence, and the smallest edit that keeps the writer recognisable.

## Two modes, like the interface filter

**Detect.** The user asks whether a draft reads as AI-generated, or asks for
an audit without a rewrite. Answer with findings, not a verdict: name the
pattern, quote the offending line, give the fix in a few words. Do not score
the draft, and do not guess who or what wrote it — a named pattern with a
quote is something the reader can check, and an authorship claim is not.
Offer the edit afterwards; do not perform it unasked.

**Edit.** Make the minimum effective change and stop. First read for the
writer's habits worth keeping: vocabulary, cadence, bluntness, humour,
uncertainty, digressions. Strong sentences that carry those habits are left
alone even when they break a tidiness rule, and no rewrite adds a claim,
example, statistic or opinion the draft did not contain — if a sentence
needs a real fact to work, ask, or write the plainer sentence without it.

## What the copy filter's pattern list does not name

- **The portability test.** Read each sentence and ask whether it could move
  unchanged into a different person's, company's or product's text. If it
  could, it is filler: cut it, or replace it with the fact, mechanism or
  consequence specific to this subject.
- **Colon reveals.** A noun phrase, a colon, then a staged lowercase reveal
  ("The detail that makes it work: a separate pass grades it") manufactures
  drama out of punctuation. Write the plain sentence; keep colons for lists,
  labels and quotations.
- **Fake-profound endings.** A closing aphorism or mic-drop metaphor is
  deleted, not improved: rewriting it into a better metaphor keeps the
  defect. End on the last concrete point, or on a plain next action. The same
  applies to a final paragraph that only restates the piece.
- **Commentary about the prose.** Lines that instruct the reader what to
  notice ("that last part matters", "in other words") go once the prose
  itself makes the point. Show; do not stage-direct.

## The closing check, pass or fail

1. Would the writer recognise the edited draft as their own voice?
2. Did any sentence survive only because it is portable filler?
3. Is every pattern named in a detect report backed by a quoted line?
4. Did the ending land on a concrete point instead of an aphorism or recap?
5. Did the edit add nothing the draft did not already contain?

A failed check is fixed before handing over, and whether the output is a
findings list or a tightened draft, one short note says what changed.
